# Lena Plant Guide — офлайн-прототип

## Что уже работает
- Локальная база из 47 строк листа «Все растения» исходного Excel.
- Каталог с поиском по русскому и латинскому названию и семейству.
- Карточка растения со всеми признаками из таблицы.
- Опрос из 7 вопросов и ранжирование возможных совпадений.
- Приложение не отправляет данные в интернет и не требует внешних пакетов.

## Важно про данные
21 запись в Excel помечена как кандидат в краснокнижные, а 26 — как обычные растения из предварительной подборки. Это не подтверждает юридический охранный статус. В карточках статус специально обозначен как требующий проверки. Некоторые признаки в исходном Excel также предварительные. В столбце «Фото» исходной таблицы нет изображений, поэтому распознавание по фото не реализовано. Это интерактивный определитель по ответам пользователя.

## Как использовать в существующем проекте
1. Сначала сделайте резервную копию папки проекта.
2. Скопируйте папки `assets`, `lib`, `test` и файл `pubspec.yaml` из этого комплекта в корень Flutter-проекта. Подтвердите объединение папок. Этот комплект заменяет исходники внутри `lib`, поэтому заранее сохраните старую версию.
3. Если у проекта есть собственная папка `android`, `ios`, `web` и т.п., не удаляйте её. Она содержит платформенные настройки.
4. Откройте терминал в корне проекта, где лежит `pubspec.yaml`, и выполните `flutter pub get`, затем `flutter test`, затем `flutter run`.
5. В Android Studio выберите **Open** и откройте папку проекта, где лежит `pubspec.yaml`.

## Если папка проекта называется LenFlor.app
Имя папки может содержать заглавные буквы и точку, но имя пакета Dart в `pubspec.yaml` должно быть `lena_plant_guide`, как в этом комплекте. Не перемещайте и не удаляйте `C:\src\flutter` — это установленный Flutter SDK.
